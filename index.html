가격은 얼마인가요?⌄

지금 돈을 내야 하나요?⌄

아니요. 이메일만 남기는 거예요. 결제는 출시 후에 하고, 그때도 원하지 않으면 안 하면 돼요. 취소도 언제든 가능해요.

상대방이 분석한 걸 알 수 있나요?⌄

전혀 알 수 없습니다. TIKI는 오직 당신만 사용하는 분석 도구이며, 상대방에게는 어떤 알림도 가지 않습니다.

카톡 내용을 꼭 보내야 하나요?⌄

아니요. 상황 정보만으로도 진단이 가능합니다. 대화를 일부 입력하면 정확도가 올라가지만, 선택 사항입니다.

개인정보와 대화 내용은 안전한가요?⌄

입력하신 내용은 진단 목적 외에 사용되지 않으며, 제3자에게 제공되지 않습니다. 분석이 끝난 대화 데이터는 안전하게 관리됩니다.

정확도는 어느 정도인가요?⌄

TIKI는 확정적 예측이 아닌, 입력 정보 기반의 행동 가이드를 제공합니다. 방대한 대화·심리 데이터를 학습한 AI가 분석하며, 입력 정보가 구체적일수록 신뢰도가 높아집니다.

썸·연애 말고 다른 관계도 되나요?⌄

네. 어색한 사이부터 연인, 다툼 상황까지 관계 단계별로 진단이 가능합니다. 진단 시작 시 현재 관계를 선택하시면 그에 맞춰 분석됩니다.
